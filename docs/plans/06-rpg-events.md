# 6단계: RPG 프레임워크 2 — 이벤트와 상호작용

**권장 모델**: Claude Fable 5 (최소 Opus 5) — 코루틴 실행기, 조작 잠금, 병렬 이벤트, 맵 전환 중의 자원 해제는 상태 관리 버그가 숨기 쉬운 영역이다. 이 로드맵에서 가장 신중해야 할 단계.

> 목표: 맵 위의 NPC와 오브젝트에 말을 걸거나 닿으면 스크립트가 실행된다. R2K3의 이벤트 커맨드 목록을 흉내 내는 대신, **Lua 코루틴을 이벤트 스크립트로 그대로 쓴다.**
> "에디터에서 가장 중요한 건 스크립트 작성"이라는 방향과 정확히 맞물리는 단계다.

## 핵심 설계: 이벤트 = Lua 함수

R2K3는 "문장 표시", "장소 이동" 같은 이벤트 커맨드를 목록으로 쌓는 방식이지만, 우리는 이미 완전한 언어(Lua)가 있다. 이벤트 스크립트를 코루틴으로 실행하면 "대화창이 닫힐 때까지 대기" 같은 흐름이 자연스럽게 표현된다.

```lua
-- scripts/maps/map1.lua : 맵 1의 이벤트 정의 (맵 JSON과 분리, 2단계 결정 참고)
return {
  events = {
    {
      id = "villager_a",
      x = 12, y = 7,
      charset = { file = "rtp/CharSet/People1.png", index = 2 },
      trigger = "action",        -- 결정키로 말을 걸면 실행
      script = function(self, ctx)
        ctx.message("어서 오세요. 처음 보는 얼굴이네요.")
        local pick = ctx.choice({ "네, 처음입니다", "아니요" })
        if pick == 1 then
          ctx.message("천천히 둘러보다 가세요.")
        end
      end,
    },
    {
      id = "door_to_house",
      x = 20, y = 5,
      trigger = "touch",         -- 밟으면 실행
      script = function(self, ctx)
        ctx.transfer("map2", 3, 10)   -- 맵 이동
      end,
    },
  },
}
```

- `ctx.message`, `ctx.choice` 등은 내부에서 `coroutine.yield`로 완료를 기다린다 (7단계의 대화창이 공급).
- 조건 분기, 반복, 변수는 Lua 문법 그대로다. R2K3의 스위치와 변수 데이터베이스를 별도로 만들 필요가 없고, 저장이 필요한 상태만 `ctx.state` 테이블에 넣는다 (테이블 하나라 직렬화도 쉽다).
- 이벤트의 외형이 있으면 5단계의 `character.lua`를 재사용한다. 외형이 없으면 보이지 않는 트리거 타일이다.

## 트리거 종류 (R2K3 대응)

| 트리거 | 발동 조건 |
|---|---|
| `action` | 플레이어가 인접 타일에서 이벤트를 바라보고 결정키(Z 또는 Enter) |
| `touch` | 플레이어가 이벤트 타일에 들어감 |
| `auto` | 맵 진입 시 자동 실행 (완료까지 플레이어 조작 잠금) |
| `parallel` | 매 프레임 병렬 실행 (조작 잠금 없음, 각자 코루틴) |

## 작업 항목

- [x] `scripts/rpg/event.lua`: 이벤트 객체 (위치, 외형, 트리거, 스크립트, 점유 타일 관리) + 맵 하나 분량을 들고 트리거를 감지하는 관리자
- [x] `scripts/rpg/interpreter.lua`: 코루틴 실행기 — 이벤트 실행 중 플레이어 조작 잠금, `yield` 재개 조건 관리, `parallel` 이벤트의 독립 코루틴 관리
- [x] `ctx` API 1차분: `message`, `choice`, `wait(ms)`, `transfer(mapId, x, y)`, `moveRoute(who, route)`, `turn(who, dir)`, `state`. 대화창은 주입받는 `messagePort`라 7단계에서 그것만 갈아 끼우면 된다 (기본값은 print 스텁)
- [x] `map_scene.lua`(5단계)에 이벤트 통합: 통행 판정이 이벤트를 보고(`setEvents`), 관리자가 결정키(바라보는 칸 → 발밑)와 접촉(칸이 바뀌는 순간)과 맵 진입(`auto`, `parallel`)을 처리한다
- [x] 맵 전환 (`transfer`): 현재 맵 자원 해제 → 새 맵 JSON과 이벤트 파일 로드 → 페이드 아웃과 인 (`resources/ui/fade.png`를 확대하고 투명도 조절)
- [x] 이동 루트: `ctx.moveRoute("patrol", { "right", "wait:400", "up" })`. 명령은 방향, `turn:방향`, `wait:밀리초`이고 `loop`, `skipBlocked` 옵션이 있다 (`character.lua`의 기존 이동 루틴 위에 얹었다)
- [x] 페이지(조건에 따라 외형과 스크립트가 바뀌는 것)는 v1에서 제외 — `script` 안의 if문과 `ctx.state`로 대체한다. 오두막의 `enter_note`가 그 예다 (두 번째 방문에는 조용히 넘어간다)

## 완료 기준

- [x] NPC에게 결정키로 말을 걸면 스크립트가 실행되고, 실행 중에는 이동이 잠긴다. — 단위 91건과 통합 씬(`rpg_event_scene`)에서 확인. 말을 걸면 이벤트가 플레이어를 돌아본다

## 구현 노트 (2026-08-17)

- **재개는 언제나 다음 프레임**: 즉시 끝나는 요청(`turn`, `wait = false`인 `moveRoute`)도 그 자리에서 코루틴을 다시 돌리지 않고 프레임 0짜리 대기를 건다. 한 프레임에 한 번만 재개한다는 규칙이 있어야 `while true do ctx.turn(...) end` 같은 스크립트가 게임을 얼리지 않는다.
- **전환은 스크립트를 끝낸다**: `ctx.transfer` 다음 줄은 실행되지 않는다. 맵이 통째로 바뀌어 이벤트도 사라지기 때문이고, 실행기가 스스로 그 코루틴을 죽여서 씬이 `clear`를 잊더라도 조작 잠금이 남지 않는다.
- **전환은 요청이지 즉시 실행이 아니다**: 씬은 `transfer` 요청을 받아 페이드 아웃이 끝난 뒤에 맵을 교체한다. 교체 직후 `scene:update(0)`으로 스프라이트 위치를 한 번 맞춰 준다 — 페이드가 도는 동안에는 갱신 루프가 멈춰 있어서, 이게 없으면 캐릭터가 잠시 화면 좌상단에 그려진다 (실측으로 발견).
- **스크립트 오류는 그 이벤트만 죽인다**: `coroutine.resume`의 실패를 잡아 `interp.errors`에 남기고 해당 이벤트만 끝낸다. 게임이 멈추거나 조작이 잠긴 채로 남지 않는다.
- **touch는 칸이 바뀌는 순간에만**: 관리자가 플레이어의 이전 타일을 기억한다. 맵에 들어선 칸에 touch 이벤트가 있어도 진입만으로는 발동하지 않는다 (전환 직후 무한 왕복 방지).
- **대화창은 항구(port)다**: 실행기는 `messagePort.isBusy()`가 false가 될 때까지 기다릴 뿐이다. 지금 데모가 쓰는 것은 화면 아래 글자 한 줄짜리 임시 구현이고, 7단계에서 이 테이블만 창으로 갈아 끼운다.
- **데모 맵**: 2단계 골든이 `resources/maps/sample.json`을 물고 있어 건드리지 않고, 데모용으로 `village.json`(70x40, 길과 마당 셋)과 `room.json`(20x14)을 새로 만들었다. 규칙으로 생성했지만 결과 JSON만 커밋했으므로 에디터로 열어 고칠 수 있다.
- **줄바꿈과 폰트 (사용자 검수에서 나온 것)**: 대사가 창 밖으로 넘치고 글자가 너무 컸다.
  - 줄바꿈은 `scripts/rpg/text.lua`로 만들었다 — UTF-8 글자 분할과 픽셀 기준 줄 나누기. 폭 측정 함수를 주입받아 헤드리스로 검증한다 (31건). 7단계의 대화창이 그대로 쓴다.
  - 글자 크기는 폰트 파일이 곧 크기다. 엔진의 텍스트 경로에는 확대가 없으므로 16px 폰트를 새로 구웠다 (`tools/generate_bmfont.py`, `resources/fonts/hangul16.fnt`). 데모는 씬에 들어갈 때 그 폰트로 바꾸고 나갈 때 되돌린다.
  - 그 과정에서 엔진 폰트 코드의 버그 셋을 고쳤다: (1) `kernings` 블록이 없는 정상적인 BMFont 파일에서 널 역참조로 죽었다 — 필수 블록 검사를 실제로 쓰기 전으로 옮겼다. (2) `PreparaFont`가 실패를 true로 보고했다 — `Font::open`이 "이미 폰트가 하나 열려 있으면" 무조건 true라서, 잘못된 경로를 줘도 성공으로 보였다. (3) `m_fontSize`가 32로 고정이라 lineHeight가 다른 폰트를 열면 배율을 걸어 늘였는데, 확대 시 소스 사각형까지 커져 아틀라스의 옆 글자를 물고 나왔다 — 폰트를 열 때 그 폰트의 lineHeight를 기준으로 잡아 항상 1배로 그린다.
