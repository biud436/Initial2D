# 알데바란 5단계: 스테이지를 길게, 어렵게, 그리고 플롯이 있게

> 기획서: [docs/design/aldebaran.md](../design/aldebaran.md) 4.3절 (다시 썼다).
> 선행: [4단계 도트](aldebaran-4-pixelart.md).

**권장 모델**: Fable 5. 무대 전환과 플롯 장치가 씬의 상태 관리에 얽히고, 맵이
두 배가 되면서 인수 시나리오의 구조도 바뀐다.

> 목표: **걸을수록 숲이 달라지고, 달라질 때마다 이 숲에 무슨 일이 있었는지가
> 하나씩 밝혀진다.**

## 1. 지적받은 것 (2026-08-23)

1. **스테이지가 너무 짧다.** 128타일은 3분이면 끝난다.
2. **너무 쉽다.** 적 여덟에 3단 콤보면 거의 맞지 않고 지나간다.
3. **이야기가 확고하지 않다.** 표지 글 두 줄이 전부라 "걷고 때리는 것" 말고는
   남는 것이 없다. **플롯이 있어야 한다.**
4. **무대가 바뀌어야 한다.** 같은 검은 안개의 숲이라도 지날수록 배경이 달라지고,
   때로는 있을 리 없는 것이 나타나도 된다.

## 2. 답

스테이지를 다섯 구간으로 나눈다. 구간마다 **무대가 바뀌고, 위험이 달라지고,
흔적 하나가 이 숲의 내력을 한 조각 알려 준다.** 다섯 조각을 이으면 하나의 사연이
된다 (기획서 4.3.1절).

재료는 새로 지어내지 않고 **원안(`Spica_v0.9.docx`)에서 꺼내 썼다.** 원숭이가
부족이라는 것, 늑대 인간이 실험실에서 도망친 모체의 후손이며 집을 짓고 산다는 것,
안개가 열매를 태워 만든 상품이라는 것, 제단에 네 화두와 K0가 있다는 것, 그리고
**안개에 중독되면 환상을 본다**는 것까지 전부 원안에 적혀 있었다.

## 3. 마일스톤

| 단계 | 무엇을 | 눈에 보이는 결과 |
|---|---|---|
| 1. 구간과 무대 | 맵 256타일, 구간별 배경 한 벌과 겹쳐 바꾸기 | 걸으면 숲이 달라진다 |
| 2. 플롯 | 흔적과 발견 기록, 환상, 에필로그와 결과 창 | 지날수록 이야기가 쌓인다 |
| 3. 난이도와 검수 | 적 열여섯, 검은 늑대, 보스 두 판, 인수 다시 쓰기 | 쉽게 지나갈 수 없다 |

## 3.5 레벨 디자인 원칙 (2026-08-23 지시)

적과 지형을 눈대중으로 흩지 않는다. 다섯 구간이 곧 학습 곡선이 되게 짠다.

### 가르치고, 시험하고, 비튼다

| 배울 것 | 가르치는 자리 | 시험하는 자리 | 비트는 자리 |
|---|---|---|---|
| 베기 | 1구간 평지의 거미 하나 (혼자, 안전하다) | 2구간 턱 위의 거미 | 2구간 끝의 거미 둘 |
| 점프 | 1구간의 1타일 턱 (실패해도 다치지 않는다) | 1구간 끝의 2타일 턱 위 거미 | 2구간 계단 넷 |
| 건너뛰기 | 3구간 첫 다리의 두 칸 구멍 | 둘째 다리의 세 칸 구멍 | 셋째의 다섯 칸 (대쉬나 2단 점프가 필요하다) |
| 버서커 | 4구간 첫 늑대 둘 (여기서 처음 필요해진다) | 4구간 둘째 늑대 둘 | 검은 늑대 |

**새 위험은 안전한 자리에서 먼저 보여 준다.** 첫 낭떠러지는 구멍이 두 칸이라
그냥 걸어도 넘어가고, 실패해도 바로 아래가 다리다.

### 보이고 나서 다친다

- 착지 지점 바로 옆에 적을 두지 않는다. 뛰어내린 순간 맞는 것은 실력이 아니라 사고다.
- 적은 화면에 **먼저 보이고** 나서 다가온다. 경계 범위(96~150px)가 화면 폭(384)보다
  좁으므로, 적을 구간 경계에서 최소 100px 안쪽에 둔다.

### 쉬는 박자

싸움 - 이동 - 발견 - 싸움 순으로 갈마든다. **흔적은 싸움이 끝난 자리에 둔다.**
글을 읽는 동안 맞으면 안 되기 때문이다.

체크포인트는 **어려워지기 직전**에 둔다 (2구간 끝의 석주는 다리 앞, 4구간 초입의
우리는 늑대 무리 앞). 어려운 곳을 지난 뒤가 아니라.

### 레벨이 오르는 자리를 설계한다

레벨이 오르면 HP와 MP가 가득 찬다. 즉 **레벨 업이 곧 회복 지점**이므로, 필요
경험치와 구간별 적의 경험치를 맞물리게 한다.

| 구간 | 그 구간의 경험치 | 누적 | 레벨 |
|---|---|---|---|
| 1 (거미 2) | 10 | 10 | **2** (구간 끝에서 오른다. 회복하고 2구간으로) |
| 2 (거미 4) | 20 | 30 | **3** (다리 앞에서 오른다) |
| 3 (거미 2, 늑대 1) | 18 | 48 | **4** (마을에 들어가기 전에 오른다) |
| 4 (늑대 4, 검은 늑대 1) | 48 | 96 | **5** (마을 안에서 오른다) |
| 5 (늑대 1, 짐도둑) | 20 | 116 | **6** (보스전 중에 오른다) |

전부 잡은 플레이어만 이 회복을 받는다. 지나친 플레이어는 낮은 레벨로 보스를 만난다.
**난이도는 적의 수가 아니라 이 선택으로 갈린다.**

## 4. 마일스톤 1: 구간과 무대

### 4.1 맵

`generate_aldebaran_maps.py`를 128에서 **256타일**로 늘리고, 구간마다 지형의
성격을 다르게 한다.

```
   0~ 47   1. 숲 입구      평탄한 진흙 길. 얕은 턱 둘
  48~ 99   2. 옛 길        포석이 깔린 오르막. 바위 턱 넷이 계단으로
 100~147   3. 기암 절벽    낭떠러지와 낡은 다리 둘. 아래로 강이 흐른다
 148~203   4. 늑대 마을    오두막과 우리. 높낮이가 잦고 좁다
 204~255   5. 제단 앞      트인 공터. 마름모 제단과 네 화두
```

구간 경계는 **지형으로 표시한다.** 문이나 벽이 아니라, 바위 어깨나 다리처럼
"여기서부터 다른 곳"이라고 느껴지는 지형을 둔다.

### 4.2 무대 바꾸기

구간마다 배경 한 벌을 만든다.

| 구간 | 먼 숲 | 가까운 숲 | 하늘과 안개 |
|---|---|---|---|
| 1 | 마른 검은 나무 | 검은 나무 | 지금 그대로 |
| 2 | 나무가 성기고 **석주**가 선다 | 나무 몇과 포석 | 안개가 옅다 |
| 3 | **먼 산과 골짜기** | 절벽면 | 하늘이 트이고 별이 많다 |
| 4 | 나무가 빽빽하다 | **오두막과 매달린 우리, 모닥불** | 안개가 짙고 붉다 |
| 5 | 트인 하늘 | **마름모 제단과 화두 넷** | 알데바란이 크게 뜬다 |

씬은 카메라 x로 지금 구간과 다음 구간을 알아내고, 경계 앞뒤 **96픽셀에서 두 벌을
겹쳐 서서히 바꾼다.** 스프라이트의 투명도로 하므로 엔진은 손대지 않는다.

붉은 눈은 배경이 아니라 **가까운 숲 그림에 그려 넣는다.** 구간이 깊어질수록 수가
늘어난다 (1구간 한 쌍, 4구간 네 쌍).

### 4.3 완료 기준

- [x] 스테이지가 256타일이고 구간마다 지형의 성격이 다르다
- [x] 걸어서 경계를 지나면 배경이 갑자기 갈리지 않고 서서히 바뀐다
- [x] 다섯 구간의 배경이 서로 확실히 구분된다 (스크린샷 다섯 장)

## 5. 마일스톤 2: 플롯

### 5.1 흔적과 발견 기록

구간마다 **흔적** 하나를 둔다. 밟으면 지금처럼 화면 위에 글이 뜨고, 동시에
**발견 기록에 남는다.**

```lua
    Stage.LANDMARKS = {
      { x0 = 300, x1 = 340, id = "tracks", title = "여러 갈래의 발자국",
        text = "발자국이 여럿이다. 도둑은 혼자가 아니었다." },
      ...
    }
```

- `status().found` 로 밖에서 볼 수 있게 한다 (인수 시나리오가 확인한다).
- 결과 창에 **알아낸 것 n/5** 와 제목 목록을 보여 준다.
- 다섯을 다 모으면 에필로그에 한 줄이 더 붙는다 (도둑이 지도를 노린 까닭).

흔적은 **강제가 아니다.** 지나쳐도 스테이지는 끝난다.

### 5.2 안개에 취해 보는 환상 (기획서 4.3.2절)

4구간의 흔적(우리)을 밟으면 3초 동안 **배경이 옛 숲으로 바뀐다.** 밝은 하늘과
초록 잎. 그리고 다시 안개가 덮는다.

- 배경 한 벌(`forest_bright`)을 더 만들고, 그동안 그것을 위에 겹쳐 그린다.
- 조작을 잠그지 않는다. 컷씬이 아니라 **환각**이므로 걷는 중에 일어나야 한다.

### 5.3 완료 기준

- [x] 다섯 흔적이 각각 다른 구간에 있고, 밟으면 글이 뜨고 기록에 남는다
- [x] 결과 창이 알아낸 것을 보여 준다
- [x] 다섯을 다 모았을 때만 에필로그의 마지막 줄이 붙는다
- [x] 우리 앞에서 잠깐 옛 숲이 보이고, 그동안에도 걸을 수 있다

## 6. 마일스톤 3: 난이도와 검수

### 6.1 적

| 구간 | 적 |
|---|---|
| 1 | 전갈거미 둘 |
| 2 | 전갈거미 넷 (둘은 턱 위에서 기다린다) |
| 3 | 전갈거미 둘, 늑대 하나 (다리 건너) |
| 4 | 늑대 넷(둘씩 두 번)과 **검은 늑대** 하나 |
| 5 | 늑대 하나, 짐도둑 |

- **검은 늑대**: 종별 표에 하나 더한다. HP와 공격이 늑대의 1.5배, 돌격을 다시 쓴다.
- 4구간의 늑대는 순찰 구간을 겹쳐 두어 **둘이 함께 달려든다.**
- 체크포인트를 둘로 (2구간 끝, 4구간 초입).

### 6.2 보스 두 판

HP가 절반이 되면 제단 위로 올라가 **돌을 두 개씩** 던진다. `monster.lua`의
투척형에 `phase2` 하나를 더한다.

### 6.3 인수 시나리오

맵이 두 배가 되고 흔적이 생겼으므로 다시 쓴다. 이번에는 **좌표를 박아 넣지 않는다.**

- 지금은 점프할 x를 목록으로 박아 두어 맵이 바뀌면 통째로 깨진다.
- 앞이 막혀 더 나아가지 못하면 뛰는 **자동 조종**으로 바꾼다. 그러면 지형이 바뀌어도
  시나리오가 산다.
- 확인할 것: 구간 다섯을 다 지나는가, 흔적 다섯을 다 줍는가, 검은 늑대를 잡는가,
  보스가 두 판을 도는가, 에필로그의 마지막 줄이 붙는가.

### 6.4 완료 기준

- [x] 적이 열여섯이고 뒤 구간일수록 촘촘하다
- [x] 검은 늑대가 늑대와 구분되고 더 세다
- [x] 보스가 절반에서 두 번째 판으로 넘어간다
- [x] 인수 시나리오가 좌표를 박지 않고도 끝까지 통과한다
- [x] 전체 스위트 통과, C++ diff 0

## 7. 이 단계가 하지 않는 것

- **스테이지 1-2 (황제의 무덤).** 지도의 표시로 예고만 한다.
- **날씨(낙뢰) 연출.** 기획서에는 적었지만 화면 효과가 필요하므로 다음으로 미룬다.
- **원숭이 부족 전투.** 도둑 하나로 끝낸다. 부족은 흔적의 글로만 존재한다.

## 8. 하고 나서 (2026-08-23)

### 더해진 것: 힘과 쿨타임

작업 중에 지적이 하나 더 왔다. **"뭔 보물 사냥꾼이 단검으로 늑대 인간을 잡나."**
맞는 말이라 기획서에 5.3절을 새로 썼다. 흔적 다섯이 힘 다섯을 준다. 셋은 늘
켜져 있고 둘은 쿨타임이 있는 스킬이며, 화면 오른쪽 위 슬롯에 남은 시간이 보인다.

이로써 플롯과 성장이 같은 진행이 되었다. **이야기를 읽은 사람이 강해진다.**

### 레벨 디자인에서 고친 것

첫 낭떠러지를 **얕은 도랑**으로 바꿨다. 처음 설계는 두 칸 구멍 아래가 바로
낭떠러지였는데, 그러면 "가르치는 자리"에서 목숨을 잃는다. 도랑 바닥을 다리보다
두 칸 아래에 두어 빠져도 뛰어서 나오게 했다.

다리 높이도 틀렸었다. 어깨보다 두 칸 위에 놓아 올라갈 수가 없었고, 자동 조종이
그 앞에서 멈춰 처음 알았다. **지형은 눈으로 그리지 말고 지면 높이를 계산해 놓아야
한다.**

### 인수 시나리오에서 배운 것

맵이 두 배가 되면서 좌표를 박아 둔 시나리오가 통째로 깨졌다. 다시 쓰면서
**맵을 모르는 자동 조종**으로 바꿨다.

1. 앞이 막혀 x가 늘지 않으면 뛴다.
2. 뛰지 않았는데 공중이면(발을 헛디뎠으면) 곧바로 공중 점프로 건넌다.
3. 벨 수 있는 거리에 적이 있으면 벤다. 늑대면 폭주를 먼저 쓴다.

이 셋만으로 256타일을 끝까지 간다. 지형을 또 고쳐도 시나리오는 살아남는다.

**터치 검사에서 한 번 걸렸다.** 걷기와 점프를 먼저 확인하고 공격을 나중에 보게
짜 두었더니, 그 사이에 첫 거미가 붙어 피격 경직에 걸려 공격이 먹지 않았다.
공격을 맨 앞으로 옮겼다. 검사 순서도 게임 상태를 만든다.
