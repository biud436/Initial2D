# 5단계: RPG 프레임워크 1 — 캐릭터 렌더링과 이동

**권장 모델**: Claude Opus 5 — 명세가 상세한 Lua 구현이며, 이동의 손맛 같은 짧은 조정을 여러 번 반복하는 작업이다. 로드맵의 최소 기준선인 Opus 5로 진행한다.

> 목표: CharSet 캐릭터가 타일맵 위를 걸어다닌다. 4방향 걷기 애니메이션, 그리드 이동, 충돌, 카메라 추적까지.
> 여기서부터 RPG 프레임워크 레이어다. **전부 Lua**(`scripts/rpg/`)로 작성하며 C++ 수정은 원칙적으로 없다.

## 구조

```
scripts/rpg/
  specs.lua       -- 리소스 규격 데이터 (4단계)
  character.lua   -- 맵 위의 움직이는 객체 (플레이어와 NPC 공용)
  player.lua      -- 입력을 character에 연결
  camera.lua      -- 대상 추적, 맵 경계 클램프
  map_scene.lua   -- 타일맵 + 캐릭터들 + 카메라를 묶는 씬
```

## 핵심 설계

### character.lua

플레이어와 NPC가 같은 클래스를 쓴다. 상태는 단순하게 유지한다.

- 위치는 **타일 좌표**(`tx, ty`)가 진실이고, 픽셀 좌표는 이동 보간 중에만 어긋난다. R2K3와 같은 그리드 이동 방식.
- `moveTo(dir)`: 목표 타일이 통행 가능하면(`Tilemap.IsPassable` + 다른 캐릭터 점유 검사) 보간 이동 시작. 이동 중에는 새 입력을 큐에 하나만 보관.
- 걷기 애니메이션: CharSet 프레임 3장을 `왼발, 중립, 오른발` 순으로 재생하되 실제 걸음 패턴은 `중립, 왼발, 중립, 오른발` 반복. `Sprite.SetSheetGrid`(1단계)와 `SetRect`로 시트에서 잘라 쓴다. 시트 안의 캐릭터 인덱스(0~7)와 방향 행 매핑은 `specs.lua` 데이터를 따른다.
- 방향 전환: 정지 상태에서 다른 방향키를 짧게 누르면 이동 없이 방향만 바꾸는 R2K3식 처리(선택 사항이지만 손맛에 크게 기여).

### 그리기 순서

- 타일맵 하층 → 캐릭터들(y좌표 오름차순 정렬) → 타일맵 상층 순으로 그린다. 2단계의 `Tilemap.Draw(handle, layerFrom, layerTo, camX, camY)` 레이어 분할이 이를 위한 것이다.
- y정렬은 Lua 테이블 `table.sort` 한 줄이면 된다. 코어에 z순서를 넣지 않기로 한 결정(1단계)이 여기서 검증된다.

### camera.lua

- 대상(플레이어)의 픽셀 좌표를 따라가되 맵 경계에서 멈춘다 (맵이 화면보다 작으면 가운데 정렬).
- 카메라는 값(오프셋)일 뿐이며, 모든 그리기 호출에 빼서 전달한다.

## 작업 항목

- [ ] `character.lua`: 생성(CharSet 경로, 시트 내 인덱스, 시작 타일), 방향, 걷기 애니메이션, 그리드 보간 이동, 통행 판정
- [ ] `player.lua`: 방향키 입력 처리 (`Input.IsKeyDown`), 이동 큐
- [ ] `camera.lua`: 추적과 클램프
- [ ] `map_scene.lua`: 맵 로드, 캐릭터 등록, y정렬 그리기, 갱신 루프
- [ ] NPC 자동 이동(랜덤 걷기)을 `character.lua`의 이동 루틴으로 구현 — 6단계의 이동 루트 기능의 토대. 난수는 반드시 시드 주입이 가능한 `rpg.rng` 래퍼를 통해서만 쓴다 (결정적 재생을 위한 규칙, [09-testing.md](09-testing.md) 4절)
- [ ] 데모 씬: 에디터로 만든 맵(3단계 산출물) 위에서 플레이어가 걸어다니고 NPC 두어 명이 배회

## 완료 기준

- [ ] 플레이어가 방향키로 맵을 걸어다닌다. 벽과 NPC를 통과하지 못하고, 걸음 애니메이션이 자연스럽다.
- [ ] 화면보다 큰 맵에서 카메라가 부드럽게 따라오고 경계에서 멈춘다.
- [ ] 캐릭터가 상층 타일(지붕 등) 뒤로 지나갈 수 있다 (레이어 분할 그리기 검증).
- [ ] C++ diff가 0이다 (이 단계에서 코어 수정이 필요했다면 1단계나 2단계로 되돌아가 범용 기능으로 넣는다).
