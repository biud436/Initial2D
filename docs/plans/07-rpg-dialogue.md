# 7단계: RPG 프레임워크 3 — 대화창과 윈도우 UI

**권장 모델**: Claude Opus 5 — 스킨 조립, 줄바꿈, 타자 효과 등 시각적 반복 조정이 중심이다. 코루틴 연동의 어려운 부분은 6단계 산출물을 그대로 사용한다.

> 목표: System 윈도우 스킨으로 대화창을 그리고, 한 글자씩 출력되는 메시지, 얼굴 그래픽, 선택지를 만든다.
> 전부 Lua(`scripts/rpg/window.lua`, `message.lua`)다. 나인 슬라이스 같은 개념을 C++에 넣지 않고, `Sprite.SetRect`로 스킨 조각을 잘라 Lua에서 조립한다.

## 재료 확인

- **윈도우 스킨**: RTP `System/System.png` (160x80, 4단계에서 투명 변환). 배경, 프레임, 선택 커서, 페이지 넘김 화살표, 글자색 팔레트가 한 장에 들어 있다. 세부 분할 좌표는 구현 시 실물 이미지와 EasyRPG Player의 Window 구현을 교차 확인해 `specs.lua`에 확정 기록한다.
- **한글 폰트**: `resources/fonts/hangul.fnt` (BMFont, 나눔고딕, lineHeight 32, 한글 음절 2453자)가 이미 동작한다. 단, 코드포인트 허용 범위가 라틴1과 한글 음절뿐이므로(`src/Font.cpp:233`) 한자와 특수문자는 안 나온다 — 데모 텍스트는 이 범위 안에서 작성한다.
- **텍스트 측정**: 1단계의 `GetTextWidth` 바인딩이 선행 조건이다 (줄바꿈 계산에 필수).
- **해상도 주의**: 스킨과 폰트의 배율이 어긋나기 쉽다. RTP 스킨은 320x240 기준이고 hangul.fnt는 32px 기준이므로, 논리 해상도를 640x480으로 잡고 스킨을 2배로 그리면 폰트와 궁합이 맞는다. 데모 초기값으로 삼고 실물로 조정한다.

## 핵심 설계

### window.lua — 범용 창 (RPG 프레임워크 안의 공용품)

- 스킨 조각을 잘라 창을 조립: 네 모서리, 네 변(반복 또는 늘이기), 배경(늘이기)
- 창 열기와 닫기 애니메이션 (세로 스케일 또는 투명도)
- 내용은 콜백으로 그린다 (메시지 창, 선택지 창, 이후 메뉴 창이 공유)

### message.lua — 대화창

- 화면 하단 고정 크기 창, `ctx.message(text, opts)`로 호출 (6단계의 코루틴 인터페이스 구현체)
- **한 글자씩 출력** (타자 효과): UTF-8 문자 단위로 진행, 결정키로 즉시 전체 표시, 다시 결정키로 닫기
- **자동 줄바꿈**: `GetTextWidth`로 어절 단위 폭을 재서 접는다 (한국어는 어절 단위 접기면 충분, 초과 시 글자 단위)
- 3줄 초과 시 페이지 넘김 (스킨의 대기 화살표 표시)
- `opts.face = { file, index }`: FaceSet 48x48을 좌측에 표시, 텍스트 영역을 그만큼 밀기
- `opts.name`: 이름 표시 (본문 첫 줄 또는 작은 이름 창, 구현하며 택일)

### choice.lua — 선택지

- `ctx.choice({ ... })`: 메시지 창 우하단 또는 별도 창에 항목 나열, 스킨 커서 사각형으로 선택 표시, 위아래 키와 결정키, 취소키(X 또는 Esc) 처리
- 반환값은 선택 인덱스 (취소 시 nil 또는 지정 인덱스)
