## 표 5

- 절: 2.3 캐릭터의 이동
- 설명: 조작 인터페이스를 이용한 조합으로 캐릭터가 어떤 행동을 취할 수 있는 지를 나타낸 표이다.

| 조작 구분 | 내용 |
|---|---|
| 기본 이동 | 패드를 왼쪽이나 오른쪽으로 한 번 터치하거나 터치하는 중에 기본 속도로 이동을 한다 |

| 점프 | 이동 패드의 상에 위치한 버튼을 터치하면 캐릭터가 제자리에서 낮게 도약한다. |
| 2단 점프 | 이동 패드 상 버튼을 빠르게 두 번 연속으로 터치하면 제자리에서 점프 보다 높게 도약한다. |
| 액션 | 액션 버튼을 터치할 경우에 캐릭터가 공격력을 가지고 전방에 공격을 가한다. |
| 스킬 | 해당 아이콘을 터치할 경우 습득하여 장착한 스킬을 사용할 수 있다. |
